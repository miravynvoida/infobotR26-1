# Информационный бот группы Р 26-1 + мини-приложение «Дневник студента»

Telegram-бот для студентов группы **Р 26-1** (русская «Р», с пробелом) + мини-приложение
с дневником: расписание, ДЗ, учебники, оценки из Google Таблицы, посещаемость, админ-панель.

- **Бот:** aiogram 3 (long polling) + APScheduler + SQLite
- **Мини-приложение:** FastAPI (сервер + API) + HTML/CSS/JS без сборки, единый дизайн на всех платформах (тёмная «глубинная» и светлая темы)
- **Оценки:** Google Таблица через сервисный аккаунт (gspread), синхронизация по кнопке

## Возможности

**Студентам:** вход по ФИО + индивидуальному коду → первичная настройка уведомлений; главное меню
с живым статусом («идёт пара / перемена / следующая пара через N мин / на сегодня пар больше нет»);
расписание (сегодня/завтра/календарь с переключением месяцев, статусы ✅🔴⏳ только для сегодня);
ДЗ с пометками «новое ✳️» и «выполнено», файлы приходят **первыми**, затем описание; учебники;
личный кабинет (средний балл, Н/Б/О, настройки уведомлений); утренний опрос «будете ли вы на парах».

**Уведомления (нельзя отключить):** опрос посещаемости за 60 мин до первой пары с напоминаниями
за 40/20/10 мин неответившим, сводка старосте/замам/админам за 5 мин; новые ДЗ; важные рассылки.

**Уведомления (настраиваются):** напоминание перед каждой парой (5–90 мин, по умолчанию 30),
расписание на завтра (по умолчанию в 19:00) с ДЗ на завтра, прочие. ДЗ автоматически уходит
в архив в **18:00 дня сдачи**.

**Админам (кнопка в боте только у ADMIN_IDS + раздел в приложении):** ДЗ (мастер создания:
дисциплина → название → задание → срок из ближайших пар или своя дата → пояснение → файлы →
предпросмотр → публикация с рассылкой; редактирование, архив, удаление); расписание (импорт
JSON из вашего промпта + ручной редактор любого дня); студенты (коды входа, привязки, добавление);
дисциплины (название/эмодзи/преподаватель); учебники; обзор и статистика; синхронизация оценок;
рассылка всем.

**Мини-приложение:** вкладки Главное / Расписание / Оценки / Кабинет; недели с выпадающим списком
(кастомная «стеклянная» шторка — одинаково на iOS/Android/Desktop), календарь, поиск следующей
пары по дисциплине; оценки — средний балл (кольцевая диаграмма), Н/Б/О, все дисциплины с историей;
ДЗ и учебники блоками по дисциплинам, «прислать материалы в Telegram» (файлы идут по file_id);
тема тёмная/светлая; сводные данные посещаемости для старосты/замов; админ-раздел.

## Переменные окружения

Скопируйте `.env.example` → `.env` и заполните (обязательно `BOT_TOKEN`, `ADMIN_IDS`):

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен из BotFather |
| `ADMIN_IDS` | TG ID через запятую — видят админ-панель (впишите и себя, и старосту при желании) |
| `MONITOR_IDS` / `DEPUTY_IDS` | староста / зам — получают сводные посещаемости |
| `WEBAPP_URL` | HTTPS-домен web-app, который выдаёт bothost.ru |
| `SUPPORT_URL` | ссылка на ваш аккаунт (кнопка «Помощь») |
| `GROUP_NAME` | по умолчанию `Р 26-1` |
| `SPECIALTY` | «Системы радиосвязи, мобильной связи и телерадиовещания» |
| `FIRST_WEEK_START` | `2026-09-02` — 1-я учебная неделя (02–06.09), дальше пн–вс |
| `DATA_DIR` | локально `data`, на хостинге `/app/data` |
| `GOOGLE_SHEET_ID` | ID таблицы оценок (из её URL) |
| `GOOGLE_SERVICE_ACCOUNT_FILE` | путь к JSON-ключу сервисного аккаунта |
| `PORT` | порт HTTP-сервера (на bothost должен совпадать с настройкой бота, по умолчанию 8080) |

## Локальный запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # заполните BOT_TOKEN и ADMIN_IDS
python -m bot
```

Или Docker: `docker compose up -d --build`.

При первом запуске БД создаётся автоматически: **25 студентов** из списка группы и **15 дисциплин**
с преподавателями. В консоль и в админку (Студенты) выводятся **индивидуальные коды входа** —
раздайте их одногруппникам.

## Деплой на bothost.ru

1. Запушьте **код** в публичный GitHub-репозиторий (данные и секреты не попадают: `.gitignore`
   закрывает `data/` и `.env`).
2. В bothost создайте бота из репозитория (Docker). Секреты положите в `/app/data/.env`
   (или переменные в панели): `BOT_TOKEN`, `ADMIN_IDS`, `WEBAPP_URL`, `SUPPORT_URL`,
   `GOOGLE_*`, `DATA_DIR=/app/data`.
3. Включите «Использовать домен» (web-app) и укажите порт `8080` — платформа выдаст
   HTTPS-домен (например `bot-… bothost.tech`), впишите его в `WEBAPP_URL` (с `https://`).
4. Бот работает на long polling — webhook настраивать не нужно. Мини-приложение открывается
   кнопкой «🖥 Открыть приложение». При желании в BotFather `/setmenubutton` можно повесить
   приложение на кнопку меню.

## Google Таблица оценок

1. В Google Cloud Console создайте сервисный аккаунт, скачайте JSON-ключ → положите в
   `data/service-account.json` (на хостинге `/app/data/`).
2. Дайте этому аккаунту доступ к таблице (Редактор).
3. Структура: **лист = дисциплина** (название как в боте: «Математика», «Ин. язык»…);
   столбец A — номер, **B — ФИО**, C и далее — даты `дд.мм.гггг`; в ячейках: `2 3 4 5`,
   `Н` `Б` `О` (русские), `Зачет` `Незачет`.
4. Синхронизация — кнопка «🔄 Синхронизировать оценки» в админке (Обзор и статистика)
   в боте или в приложении.

## Импорт расписания

Админка → Расписание → Импорт JSON. Формат — ровно тот, что возвращает ваш промпт
(`format_version: 1`, `weeks[].lessons[]` с `date/start/end/discipline/lesson_type/room`).
Импорт заменяет только те дни, которые есть в файле; неизвестные дисциплины создаются
автоматически (с предупреждением). Пары нумеруются по стандартному времени звонков:
08:30–10:00, 10:10–11:40, 11:50–13:20, 13:50–15:20, 15:30–17:00, 17:10–18:40, 18:50–20:20.
Часовой пояс — Москва (UTC+3). Учёба пн–сб, воскресенье — выходной.

## Отладка мини-приложения в браузере

Задайте `WEBAPP_DEBUG_FIO=Иванов Пётр Сергеевич` (фамилия из списка) — API впустит без initData
(только если студент уже нажимал /start, чтобы у него был tg_id). Не используйте в проде.
